# MaaBanGDream v1.5.3

发布日期为 2026-11-15。

## 🐛 修复

- 🧹 缓存清理移至后台。目录逐项处理，避免递归占用调用栈；清理期间禁用按钮，结束后显示实际释放空间和未清理原因。正在使用的日志会保留。
- 🔋 有限次数演出按剩余局数和每局耗火补充。火罐能凑齐时精确补齐；凑不齐时在剩余需求内覆盖尽可能多的局，连下一局都补不够时提示并继续原任务。
- 🎵 协力开演减少配置步骤的额外等待，保留页面确认所需等待。普通版与 FULL 版共用封面时，协力和竞演按实际标题消歧。

## 📦 更新方式

- 📥 Windows x64 首次使用请下载完整包并解压。已有便携 Python 的安装可使用更新包；更新保留配置、Profile、日志和本地谱面。
- 📢 版本说明可在「关于我们 → 更新日志」查看。两种安装包均提供 SHA-256 校验文件。

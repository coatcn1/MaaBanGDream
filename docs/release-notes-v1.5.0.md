# MaaBanGDream v1.5.0

状态：发布候选，尚未发布。

## ✨ 新功能

- 🛑 实际演出期间点击停止时增加确认，默认继续演出；排队、导航等阶段保持直接停止。
- 🎁 新增活动交易所任务，按预算和奖池剩余奖励规划抽取，保留消费确认与未决记录保护。
- 🎮 协力与竞演新增 AutoEnd / AutoContinue 自动跳车选项，默认关闭；按游戏 UID 隔离网络，确认恢复并回到安全主页后才允许续跑。
- 🎯 已启用判定反馈微调时，应用调整后仍继续采集反馈；相关实验选项保持默认关闭。

## 🐛 修复

- 🔢 交易所确认页余额改用保留完整文字的紧边界补读，解决过多留白使可信读数置信度不足的问题；不降低全局阈值，仍要求连续帧、数量、金额和余额一致。
- 🔥 统一体力补充预览读取；LIVE BOOST 面板关闭失败时有界重试，并确认页面实际切换。
- 🛡️ 自动跳车增加触点释放、人工停止、设备身份和网络恢复门禁；网络规则只清理本次拥有的精确规则，查询失败保留未决状态。
- 🚪 匹配卡死恢复仅在可信弹窗上取消或返回；重新确认目标房型后才重入，已入房或未知页面不复用旧确认坐标。
- 🏠 协力自动跳车确认正文同步采用当前字号模板；重连后最多被动等待 15 秒，连续两次确认干净主页，避免将正常黑场或漫画加载误报为恢复失败。
- 🔤 Windows 框架测试显式按 UTF-8 读取子进程输出。

## 📦 更新方式

- 🔄 通过客户端 GitHub 更新入口安装；首次安装下载完整 Windows x64 包并完整解压。更新包不含 Python 运行库归档及 `resource/charts`，已有配置、Profile、谱面、运行库和消费保护记录继续保留。
- 📁 发布后目录规范为 `MaaBanGDream-v1.5.0-win-x64`。谱面从“设置 → 谱面更新”单独同步。

## 🔒 已知限制

- ⚠️ 自动跳车需要可用的 root 能力；无 root 时安全退回手动流程。MuMu 与雷电的实际覆盖按上方验证记录区分；归零局不计完成数，成功自动跳车仍保留演出失败的任务状态。
- 🎯 现有演奏算法与实验功能仍有设备及模式边界，本版不保证 AP，也不宣称解决所有生命归零、卡顿或漏判。
- 🪟 双 MFA 或快速切换配置的上游 Avalonia 崩溃尚未修复，不要与其他自动化工具同时控制同一设备。

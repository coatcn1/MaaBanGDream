# MaaBanGDream v1.4.2

本次修复组曲选曲页未打开时误判难度，以及正常演奏结束后因重复识别标题而结算失败的问题。
准备页身份缺失或冲突时改用本局开场封面和实际标题作最后兜底。

## 🐛 修复

- 🎚️ 组曲选曲前确认难度按钮布局连续稳定出现；页面未送达时最多重试三次，未确认前不发送随机或难度输入，避免把总览页综合力红字误判为 Easy。
- 🧾 演奏完成后沿用开演前已确认的歌曲身份，不再以结果页标题、难度或等级的重复 OCR 否决演奏。组曲三张 PGGBM 按曲序保存，保留页面标记、稳定数字、总判定数和翻页确认。
- ⏱️ 修正组曲稳定数字计时反复重置的问题；读数相同时持续累计稳定时长，无法通过总判定数校验时继续等待。
- 🛡️ 单人及组曲准备页身份缺失或冲突不再提前结束：隔离旧谱面、延迟 Native 预武装，由最终封面和实读标题独立确认；最终仍不可信时不发送演奏触控。
- 🎵 兼容已验证的 `蒼穹へのトレイル`、`黒のバースデイ` Expert 区服等级差异，例外严格绑定歌曲、难度与谱面 SHA。

## 🔎 诊断增强

- Native 轻度调试异步保留首次快速掉血前后约两秒、最多 21 张已有监控截图；队列满时丢弃并计数，不新增截图或同步写盘。
- 本版本没有改动 Native 演奏时序，不把掉血取证描述为偶发死亡原因已经修复。

## 📦 更新方式

- 已安装用户可使用软件内更新，或下载不含 Python 运行库和本地谱面的更新包；谱面可在“演出设置 → 谱面辅助 → 同步”更新。
- 首次安装请下载完整 Windows x64 包，完整解压后启动。

## ✅ 验证

- 自动化：完整验证 `1177 passed / 6 skipped`；固定运行时为 Python 3.12、MaaFw 5.10.2、MFAAvalonia 2.12.0。
- 雷电真机：Hard 自由巡演连续三组、九首，全部完成演奏并保存九张稳定 PGGBM，以本次要求的 `9/9` 成功返回主页；Native 命令全部执行、零 underflow，触点释放均确认。
- 身份冲突兜底和区服等级兼容有定向自动回归；不能由上述 Hard 组曲结果外推为所有模式真机验收通过。

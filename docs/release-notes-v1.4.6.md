# MaaBanGDream v1.4.6

## ✨ 新功能

- 👥 协力成员加载页保护默认开启。“演出设置 → 任务安全”提供持久化开关，旧配置缺字段时按开启读取，显式关闭后保存并在下次任务启动时生效。协力的转场预确认与正常封面观察共用开关，避免等待成员期间错认歌曲；旧 trial 参数和环境变量不覆盖界面选择。
- 🔄 Bestdori 定时增量更新默认开启、间隔 24 小时，可在“演出设置 → 谱面辅助”关闭或设置 1–720 小时。启动与运行期间按上次成功检查时间判断是否到期，仅在全部实例没有执行或排队任务时联网；界面显示上次成功、下次检查、状态与最近错误，失败至少退避 15 分钟。
- 🎼 本地曲库更新至 822 首歌曲、1805 张 Hard / Expert / Special 谱面、880 个封面。新增歌曲、难度、元数据及缺失或损坏资源按需更新，已校验资源与 fallback 封面复用；有效旧资源使用新版本路径和原子清单提交，失败或中断保留原有可用库。

## 🐛 修复

- 🛠️ 修正成员加载页保护默认关闭且 Maa 无开关的交付缺口；协力 Native 与 Legacy 均消费持久选项，其他模式不受影响。读取设置失败时禁止将界面默认值写回。
- 🧹 修正清理缓存删除异常被吞掉后仍报告成功的问题。运行目录 `debug`、`logs`、`screencap` 及部署声明的演出记录、结果截图、MaaFramework 调试和 MFA 日志白名单目录统一规划，结果显示实际删除文件数、释放字节和未清理原因；配置、Profile、谱面及重解析点不参与清理。
- 🛡️ 多实例任务、手动/自动同步与缓存清理共用维护门禁，最后一项任务出队后仍保护谱面；维护期间新任务可取消等待。关闭自动更新只取消自动同步，确认退出后同步终止相关子进程，拒绝退出或托盘隐藏不会停止服务。

## 📦 更新方式

- 🔄 使用客户端 GitHub 更新，或下载完整 Windows x64 包。runtime-free 更新包不包含 Python 运行库和谱面库，保留个人配置、Profile、日志与调试记录；谱面由定时或手动同步独立维护。
- 📁 更新后安装目录自动改为 `MaaBanGDream-v1.4.6-win-x64`；“关于我们 → 更新日志”读取随包的本版本说明，独立公告继续单独维护。

## 🔒 已知限制

- ⚠️ Bestdori 索引不提供谱面内容版本或哈希，同音符数的远端修订无法仅靠本次元数据增量检查发现。
- ⚠️ 活动日志或外部进程占用的文件会保留并显示未清理原因，不强制解锁或终止外部进程。
- ⚠️ 协力 Legacy、Special→Expert 回退与展开表情面板未新增真实房间验收；MuMu 继续使用 Legacy。
- ⚠️ 部分歌曲仍有 GREAT / MISS，本次不修改演奏时序或 Profile timing offset，不承诺零失误。团队演出 Fes 未纳入本版本。

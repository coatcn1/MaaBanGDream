# 实时演奏引擎 V2 目标（C++ 核心唯一基线）

> 本文件替换此前的目标。此前“单人达标/随机选曲/校准”的验收是在 Python
> Legacy 引擎上做的，只算阶段证据，不算交付；本目标的唯一基线是 C++ Native
> 演奏核心接管真机热路径。

## 唯一目标

以 **C++ Native 演奏核心**为唯一基础完成所有演奏目标：

- C++ 核心接管真机热路径，固定 3 线程：实时状态/谱面调度、音符视觉、
  生命与判定条视觉；
- 触控由 **C++ 定时 minitouch 脚本后端**整曲一次性下发，带分动作类型
  （down/up/move/tap/flick）延迟补偿与取整损失补偿，绕开 Python/MaaFw
  逐条派发的延迟与抖动；
- Python 只保留 MFA 编排、导航、结算与视觉回退；
- Native 保持默认关闭开关，验证完成前不删除 Legacy，但**验收必须在
  C++ 核心上通过**。

## 真机验收（以 result JSON 为准）

1. 单人实时演奏当前曲目：连续多局 **GREAT≤5（目标 0 GREAT）** 且
   GOOD/BAD/MISS=0；
2. 随机选曲、校准依次回归；
3. 协力演奏由用户最后真机验收。

离线差分重放、C++ 单元测试、pytest 只是前置门禁，不能替代真机验收。

# 实时演奏引擎 V2 目标

> 本文件替换旧的 Native V2 交接目标（Temp/Downloads 中的两份交接文档），
> 以真机演奏结果为准。

## 唯一目标

真机单人实时演奏“当前曲目”稳定达标：**GREAT ≤ 5，且 GOOD / BAD / MISS 全为 0**，
连续多局复现。达标后再回归其他演奏功能；协力演奏由用户最终真机验收。

## 达标路径

1. 沿用 `feature/native-realtime-engine-v2` 工作树，先把现有实时引擎与已提交的
   触控/谱面修复在真机验证稳定。
2. 若无法稳定达标，按交接的固定 3 线程模型把 Native（谱面调度 +
   SongClockSynchronizer）接入真实热路径，保持 Legacy 回退与 fail-closed。
3. 每轮以真机 result JSON 为准：GREAT/GOOD/BAD/MISS、有效 FPS、分阶段耗时、
   谱面锁定状态、终止原因。

## 验收顺序

1. 单人实时演奏当前曲目：GREAT≤5 且无 GOOD/BAD/MISS，连续通过；
2. 其他演奏功能依次回归：随机选曲、一键实时演奏、自动演出、挑战演出、校准；
3. 协力演奏：留给用户真机测试，本目标只保证交付前不阻塞其启动，并提供日志与结果。

## 约束

- 修改后必须通过 `scripts/launch-mfa.ps1` 重新部署并重启 MFA；
- 判定以真机结果为准，离线重放通过不算达标；
- 实时热路径禁止 sleep / 联网 / 阻塞等待；停止与异常必须立即释放全部触点；
- 不把单人死亡/登录恢复、便携打包、定制 MFA 运行时的修改混入本次改动。

# MaaBanGDream v1.4.5

## ✨ 新功能

- 👥 协力新增“不指定歌曲 / 随机选曲 / 当前曲目”。随机和当前曲目在任务第一轮留出 10 秒筛歌窗口，期间观察停止、成员退出和玩家提前确认。
- 📊 协力 PGGBM 最多尝试读取 3 秒，确认数字稳定、置信度和已知谱面总音符数后保存至日志及结果 JSON。读不到数字只放弃统计并继续安全结算；“不检查结果”仍跳过数字读取。
- 🧪 增加默认关闭的协力成员加载页保护候选，表情图标仍在时拒绝把等待画面当作最终歌曲封面；限定协力，不影响其他模式。
- 💤 “任务运行时阻止息屏”仅在任务执行期间生效，完成、停止或失败后释放；保存的偏好保留，软件空闲时遵循系统设置。

## 🐛 修复

- 🛠️ 协力结算遇主页退出弹窗时，取消并复核弹窗消失后按主页终点收尾，避免反复按 BACK 再打开退出弹窗。
- 🛠️ Native 真实生命归零后的安全取消保留死亡原因，正式失败退出按两层确认顺序处理，避免错误分类掩盖失败或误点星石继续。
- 📢 独立公告与随包版本说明分离，更新后不叠出阅读窗口；外置更新器显示进度，后台替换和重启兼容中文路径。
- 🧪 保留默认关闭的 Native 等待成本过滤与雷电 ADB 端口归属校验候选，普通启动不自动启用。

## 📦 更新方式

- 🔄 使用客户端 GitHub 更新，或下载完整 Windows x64 包。更新包不包含 Python 运行库和谱面库，保留个人配置、Profile、日志和调试记录；谱面仍通过“演出设置 → 谱面辅助 → 同步”维护。
- 📁 更新后安装目录自动改为 `MaaBanGDream-v1.4.5-win-x64`；“关于我们 → 更新日志”读取随包的本版本说明，公告继续独立维护。
- 🤝 协力功能基于 @suwayun1 的 PR #68，补充停止响应、页面复核、稳定数字读取和 JSON 保存后合入。

## ✅ 验证

- 🧪 自动化：`scripts/verify.ps1` 为 1322 passed / 11 skipped；固定 Python 3.12、MaaFw 5.10.2、定制 MFAAvalonia 2.12.0 运行时检查通过。完整包与更新包在结构、校验和、中文路径首次启动和目录改名检查通过后发布。
- 🎮 真实设备：完成 11 首 Expert / Native 协力，输入执行数完整且触点释放均确认；前 5 首开启“不检查结果”，后 6 首稳定保存 PGGBM，一次成员退出后成功重新入房。测试启动实际开启成员加载页保护，未将这些结果外推为所有模式验收通过。

## 🔒 已知限制

- ⚠️ 部分歌曲仍出现 GREAT、BAD 或超出主动漏音数量的 MISS，本次不调整演奏引擎或 Profile 偏移，不承诺零失误。
- ⚠️ 当前曲目、首轮自动确认、Special 回退、MuMu Legacy 和展开表情面板等边界未新增完整验收；协力成员加载页保护继续默认关闭，可通过进程环境变量 `MAABANGDREAM_COOPERATIVE_MEMBER_LOADING_GUARD_TRIAL=1` 显式启用。开发启动可使用 `-CooperativeMemberLoadingGuardTrial` 参数。
- ⚠️ 任务期间连演与长期空闲息屏仍需独立覆盖；MuMu 继续使用 Legacy，双 MFA 或快速切换配置的上游渲染器崩溃仍未修复。
- ⚠️ 团队演出 Fes 未进入本版本；定制 MFA 既有 NuGet 依赖安全告警未混入本次升级处理。

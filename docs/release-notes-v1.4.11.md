# MaaBanGDream v1.4.11

发布日期：2026-10-23

## ✨ 新功能

- 🔋 各演出任务新增独立的“体力补充（仅主页）”，默认关闭，支持小火罐（+1）、大火罐（+10）或智能组合。体力足够下一局时直接继续；不足时结合剩余次数与库存规划，计划补后不超过 24 点，优先覆盖合理尾段并减少回主页次数。挑战点数独立，挑战任务不显示普通体力补充选项。
- 🧪 开场诊断采用有界截图、帧时间映射及轻量 Trace，关联房间选曲、准备送达、开演和结果；完整录像保持独立可选。
- 🎹 既有默认关闭的“Native 判定反馈微调”内增加视觉游戏相位观察候选，仅在已匹配的 1280×720、DPI 240、标准画质、60fps、流速 5.0、皮肤 1 环境使用。开场多帧建立基准，后段只按可信新帧与谱面匹配，经原门禁修正未来输入。

## 🐛 修复

- 🔌 协力和竞演开演前的连接失败弹窗按正文优先识别并有界重试，必要时取消后安全恢复主页和重新入房，避免仅凭通用“错误”标题误当成员退出。成员退出、匹配取消与重连不丢失完成次数，不消耗真实演出失败预算。
- 🛡️ 附加诊断、统计、体力、进度及报告故障降级为警告，优先保持正在演奏的输入、生命监测和触点清理。真实死亡、必要身份/Profile/输入完整性与无法安全继续的导航故障仍保留明确失败。
- 💾 校准和组曲的本任务内存进度不因附加写盘失败丢失；跨任务续跑仍要求可信落盘记录，缺失必要成绩不能接受校准 Profile。
- 📹 修正单人和挑战的完整录像配置传递，当前任务选择生效，关闭的新任务不继承旧任务设置。

## 📦 更新方式

- 🔄 通过客户端 GitHub 更新入口安装；首次安装下载完整 Windows x64 包并完整解压。更新包不含 Python 运行库和 `resource/charts`，保留配置、Profile、日志、已有谱面和体力消费保护记录；谱面从“设置 → 谱面更新”单独同步。
- 📁 更新后目录规范为 `MaaBanGDream-v1.4.11-win-x64`。等待自动重启，不要同时开启第二个客户端。

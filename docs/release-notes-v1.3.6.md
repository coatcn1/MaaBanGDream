# MaaBanGDream v1.3.6

## ✨ 更新架构

- 🔄 更新设置改用 MFA 原生 GitHub 资源更新流程，统一使用原生检查、下载进度、Toast、标题栏提示和自动更新选项，不再保留重复的 MaaBanGDream 更新卡片。

- 🛡️ 程序文件在 MFA 正常退出后由独立更新器覆盖；配置、Profile、日志、调试记录、截图与既有 runtime 均保留，版本清单最后写入。

- 🎵 漏检短黑场时，仅允许连续稳定且经本局难度、等级、标题共同确认的最终封面作为转场证据。

- 🔄 v1.3.5 会通过旧更新器检测本次正式 Release；更新到 v1.3.6 后，后续版本改用 MFA 原生 GitHub 更新器。

- 🎼 本地谱面仍通过“演出设置 → 谱面辅助 → 同步”独立更新，不进入常规更新包。

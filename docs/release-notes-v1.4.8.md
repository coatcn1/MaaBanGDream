# MaaBanGDream v1.4.8

## ✨ 新功能

- 🖼️ 最终封面长标题补全修正版（PR #82，基于 @suwayun1 的 PR #78）：保留窄框与墨迹裁剪主路径，仅在身份缺失时尝试宽框，并通过原谱面、等级、封面及实读标题门禁；高置信未知读数只接受可信的连续原文补全，不覆盖真实冲突或共享封面的不同版本。进程候选开关 `MAABANGDREAM_FINAL_COVER_WIDE_TITLE_TRIAL` 默认关闭，最终封面门控与一键实时共用该边界。
- 👥 协力房间恢复修正版（PR #83，基于 @suwayun1 的 PR #79）：普通房间仍有选择页证据时，约 12 / 24 秒最多两次重按确认，观察上限 45 秒；180 秒内未送达选曲或准备页时，最多两次主页恢复，每次最多重启游戏一次，确认主页及房间选择页后才重入。进程候选开关 `MAABANGDREAM_COOPERATIVE_ROOM_RECOVERY_TRIAL` 默认关闭，并在任务入口冻结；恢复失败不继续重入，人工停止优先中性返回，完成一局重置连续成员退出与准备超时预算。
- 🧪 “演出设置 → Native”新增“Native 掉血判定纠偏（实验）”和“Native 等待抖动过滤（实验）”，均默认关闭、自动保存，本局首次准备时冻结，修改从下一局生效。旧等待抖动环境变量不覆盖界面选择。
- 🎯 掉血纠偏仅用于 Native 正式演奏：持续掉血后短时观察判定，三个独立连续同向 FAST/SLOW 才请求一次 ±2ms 调整，本局累计不超过 ±40ms。仅在无 HOLD、无跨块事件且有足够安全空档时调整未来未发布切片，不改首音锚点、Profile timing offset 或设备命令成本；等待抖动过滤只调整未来成本预测，已发生卡顿仍计入。
- 📸 诊断记录补齐实际截图的请求时刻、帧序号、复用状态及消费者观察时刻，并保存有界判定 ROI 和分块成本快照，便于核对截图、判定与输入。截图请求时刻不代表游戏渲染时刻。

## 🐛 修复

- 💾 Native jlog 回读先更新内存回执，再由有界异步队列批量写盘；慢盘、队列满或诊断写入异常不阻塞输入派发、回执读取与释放确认，停止不等待诊断磁盘。
- 🖐️ Native 停止封闭普通发布，发送全部合法触点的 `UP → commit → reset → commit`，结合本轮请求之后的连续 jlog 与清理证据确认协议释放；历史、单个 reset、缺失或乱序回执不能代替完整序列。
- 🛠️ 修正异步预取的新截图被误标为复用，按实际返回给消费者的帧序号判断新帧；保留既有双缓冲及采样上限，不新增运行中的截图等待。
- 🎵 修正单人正式演奏在 Native 预武装前未补全模式，导致已开启的掉血反馈被错误排除的问题；排练、校准和 Legacy 保持既有边界。
- 🛡️ 挑战生命归零后停止输入、清理触点并保存缓存失败截图与结果，任务明确失败并保留现场，不自动退出、重试或推进结算；人工停止仍优先处理。
- ⚡ 通用 `CommonRefreshScreen` 显式关闭继承的框架前后延迟，加快截图轮询与页面转场观察；输入次数和节拍继续由调用方控制。
- 🖼️ 最终封面与该页实读标题共同确认歌曲。完整曲库唯一封面、标题一致且展示等级差不超过 1 级时，可使用经 ID、实际难度和 SHA 校验的谱面；共享封面、标题缺失/冲突及超过 1 级差异保持保护。歌名切换为目标得分时保留同一封面的实读歌名，协力加载页或身份未确认时继续等待，禁止旧谱面提前输入。

## 📦 更新方式

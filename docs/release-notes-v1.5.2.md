# MaaBanGDream v1.5.2

发布日期：2026-11-07

## ✨ 新功能

- 🎯 开启 Native 判定反馈后，普通单键的实际执行回执与判定共同参与本局时机恢复：首个非主动 GREAT 方向异常后提高后续单键的观察频率，三个不同按键同向异常时首次调整 60ms，实际生效后用新按键按 30ms 调整。不修改长期 Profile 时延。
- 🎲 主动 GREAT 默认偏移调整为 ±60ms；已有显式设置继续保留，不自动覆盖旧值。主动 GREAT 按逐键身份排除，不计入普通单键纠偏。
- 📷 新建或未指定演出诊断选项时，默认使用“开场截图＋轻量 Trace”，便于排查页面、标题和开场问题；已有显式选择保持不变。

## 🐛 修复

- 🔋 火罐库存数字识别不稳时，自动补体力改用实际选中数量和体力预览确认本次可用道具；保留允许类型、补充上限、消费前预扣与补后回读，消费未明时不重复确认。
- 🖼️ 相似或共享封面由最终页实读标题消歧，避免封面先匹配到其他歌曲而遮住正确候选。缺少可靠标题时继续保护，准备身份与最终可信标题冲突时在触控前停止。
- 🛡️ 完善 Native 启动探测、连续输入来源、触点释放与设备租约互斥，观察或诊断异常继续按附加功能降级处理。

## 📦 更新方式

- 📥 Windows x64 首次使用请下载完整包并完整解压；已有便携运行库的安装可使用更新包。两类包均提供 SHA-256 校验文件。
- 🔄 更新保留配置、Profile、日志和已有谱面；已有显式 GREAT 偏移与诊断选择不会被默认值覆盖。更新包不含 Python 运行库归档与本地谱面，谱面可在客户端单独同步。
- 📢 更新后主页会展示本次发布公告，完整说明也随包保留。

## ✅ 验证

- 🧪 自动化：功能代码完整验证 3914 passed / 32 skipped，Native 1964 项检查通过；独立判字器与已验收算法的结构及 71 张离线图像输出一致。定制 MFA 自动保存与旧配置兼容回归通过。
- 🎮 雷电 Native 协力：用户连续完成九局，动作计划、派发与执行数量一致，无输入欠载，触点释放均确认。另一次主动 GREAT 60ms 实测中，计划与结算均为 11 GREAT，其余非 PERFECT 判定为零，未发生普通单键误纠偏。
- 🎯 定向实测覆盖输入提前、延后 60ms 后的首次自动回正；后续 30ms 调整已有离线链路覆盖，尚未专项真机验收。
- 🔋 实测使用两个小体力道具，将体力从 1 补至 3，选择确认及补后回读成功；大体力道具和各种大库存场景尚未专项验收。

## 🔒 已知限制

- ⚠️ 实测范围不能外推为全部模式、设备或谱面的稳定保证；相似封面消歧尚未完成专项真机验收。
- ⚠️ Native 与随机 GREAT 的实际表现仍受运行环境影响，不保证实际 GREAT 比例或方向达到设置值。Native 判定反馈须开启既有选项；观察证据不足时保留输入并跳过对应纠偏。
- 💾 开场截图会额外占用磁盘空间，且有界保存、可能丢帧或截断；它与轻量 Trace 不能代替连续录像或绝对输入延迟测量。

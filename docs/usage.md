# 使用指南

安装与更新见 [Windows 运行包](release-package.md)，环境凭据见 [实时演奏 Profile](realtime-profile.md)。本页说明主分支的使用行为；发行包以随包 `resource/Release.md` 为准，具体真机覆盖见 [CHANGELOG](../CHANGELOG.md)。

## 游戏与引擎设置

实时演奏使用 1280×720、DPI 240；帧率、画质、流速和引擎须与所选 Profile 一致。

| 游戏内设置 | 值 |
| --- | --- |
| 镜像、判定辅助 | 关闭 |
| 连击数量显示 | 开启，横向右、纵向上 |
| FAST / SLOW 表示 | 开启 |
| NOTE TYPE | 1 |
| TAP EFFECT | 4 |

以上视觉选项由用户手动配置。正式准备页的 3D 演出 / 动画 MV 和 3D Cut-in 由程序按顺序关闭。

Native 在“演出设置”中显式启用，默认关闭；切换引擎后使用相应 Profile。MuMu 使用 Legacy，Native 的正式验收记录以雷电环境为主；单人结果不能替代协力、Special 或组曲验收。正式局 Native 偏移在开演前冻结，FAST / SLOW 不用于本局内重写该偏移。

## Profile 与流速

1. 运行实时校准：完成一首排练和一首正式验证，取得可接受的 Profile。
2. 在“演出设置 → 实时演奏 Profile”单击查看、双击选择当前任务难度的 Profile。
3. 改变设备环境、流速或引擎后重新校准。Expert 与 Special 属于同一兼容等级，但任务仍记录并使用实际难度。

“演出设置 → 流速 → 开演前自动设置并验证流速”开启时，每项任务在离开主页前读取、按需修正并复核；准备页不会再次打开设置。关闭时直接信任声明流速，全程不进入设置页。

一键实时在监听和开演前保持被动，不主动导航；流速检查开启时要求最近 15 分钟内已有真实读回，缺失或过期则拒绝启动。

## 任务模式与次数

| 任务 | 用法 |
| --- | --- |
| 自动演出 | 选择当前或随机曲目，使用游戏内自动演出，不调用实时触控引擎 |
| 单人实时 | 选择歌曲、难度和匹配 Profile，按准备页与最终封面门控开演 |
| 协力演出 | 支持普通房、好友邀请和六位私人房间号；可不指定、随机或使用当前曲目，并同房续演 |
| 挑战演出 | 选择点数与难度，复用正式演奏门控；不自动重试 |
| 组曲演奏 | 正式演奏完整三首，支持自由巡演、课题巡演和可信断点续跑 |
| 一键实时 | 等待新开场封面与标题，演奏一首、结算并恢复主页后结束；不会从歌曲中途启动 |
| 实时校准 | 一首排练加一首正式验证；请求 Special 时必须精确选择 Special |

带次数的任务通常接受 1–999，0 表示持续运行到手动停止或真实失败。组曲次数按歌曲计，有限次数须为 3–999 且是 3 的倍数，0 表示持续循环完整三首；只有完整一组演完后才计入三首。

单人、挑战、协力和自动演出请求 Special 时，只在该曲 Special 确认不可选后才回退 Expert。实际 Special 缺少可信本地谱面或方向信息时，在触控前停止。Easy / Normal 等无本地谱面的难度，可在身份确认后整局使用 Legacy。

### 协力

随机和当前曲目选项在首轮保留 10 秒筛歌窗口，可以提前确认或停止。准备完毕后先确认按钮消失，再持续观察成员退出、黑场和最终封面。

“演出设置 → 任务安全 → 协力成员加载页保护”默认开启，修改自动保存并在下次任务生效。成员加载页表情图标仍在时不确认歌曲；图标消失后继续等待最终封面和实读标题，演奏场匹配不会抢先结束身份扫描。“其他成员正在准备中”弹窗消失后才建立首音基线。

入房后等待选曲或准备页最多 180 秒，确认选曲后独立等待准备页 60 秒，准备后的开演转场最多观察 60 秒。PGGBM 数字最多读取 3 秒，读不到则保留统计缺失并继续结算。

生命归零时停止输入、释放触点并安全退出。等待阶段超时保留原因并有界恢复；程序不修改模拟器网络。

### 组曲

- 自由巡演：当前曲目或每首随机、统一难度；选曲页只选难度，每首在自己的准备页读取身份，连续相同歌曲合法。
- 课题巡演：使用游戏预设歌曲及难度，不修改阵容；三首 Profile 流速必须一致。
- 续跑：只有同一任务、模式、歌曲身份及阶段一致的可信断点才能续跑；旧任务的准备页不能冒充新任务。
- 重试：可重试的演奏失败会重演完整一组三首；身份、谱面或 Profile 冲突及人工停止不重试。
- 结算：第三首后按曲序尽力读取三张 PGGBM；成绩缺失或保存失败不撤销已经完成的一组。

## 歌曲身份、结果与重试

歌曲最终由本局封面、实读标题和实际难度确认，展示等级只提供辅助证据。准备页缺失或冲突时隔离旧谱面，延迟到开场最终封面补全；完整曲库唯一封面、标题一致且等级差不超过 1 时可解析本地谱面，共享封面和真实身份冲突保留保护。

第一帧有效最终封面即读取歌名，仍需连续封面稳定后确认。标题切换为目标得分时，只复用同一封面此前实读的歌名；得分不能充当标题，加载、未知或不同封面会清除缓存。未确认时继续等待，停止、真实冲突和超时按明确原因结束，不能使用旧身份输入。

演出结束后只按“最右下角安全像素 `(1279,719)` → Android BACK → 同一像素”推进，逐步截图检查；不点击奖励、排名、确定或下一步等中间按钮。身份沿用开演确认结果，结算只读稳定的 PGGBM 判定数字。

“不检查结果”跳过成绩数字读取，仍检查结算终点；校准须完整成绩才能接受 Profile。已确认演出完成后的截图、保存或恢复错误作为警告处理，不重演已完成歌曲；生命归零、未完成和用户停止仍独立记录。

失败重试在“演出设置 → 任务安全”设置 0–99，默认 1，即首次失败后最多重试一次；无限次数不取消重试预算或身份保护。

## 曲库、缓存与调试

“演出设置 → 谱面辅助”支持定时或手动同步。默认每 24 小时、所有实例无执行或排队任务时检查，可设置 1–720 小时；失败至少退避 15 分钟，失败或中断保留旧可用资源。同音符数的远端谱面修订无法仅靠索引发现，详情见[曲库说明](bestdori-chart-repository.md)。

“关于我们 → 清理缓存”只清理诊断目录，保留配置、Profile 和谱面；任务或谱面维护期间拒绝清理。结果显示实际删除量和残留原因，占用中的日志保留。

调试可选择轻度 Trace 或完整记录；同一 run ID 关联准备、最终封面、演奏、结算及清理。协力启动原帧异步、有界保存，不增加设备输入；手动流程录像用于记录页面操作。

排查时保留版本、任务模式、Profile 环境、对应结果 JSON、启动帧和 Trace。分享前隐去账号、设备序列号和本机私有信息；验收方法见[稳定性验收](realtime-stability-validation.md)。

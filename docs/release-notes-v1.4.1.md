# MaaBanGDream v1.4.1

本次版本修复组曲任务重新开始时继承旧进度，以及单曲空血后无法继续整组演奏的问题；
同时为组曲两层失败退出页使用独立识别范围，避免误点星石“继续”。

## 🐛 修复

- 🔄 **组曲空血后整组重试**：已开演的单曲生命归零或发生可分类的瞬时引擎失败时，
  先把显示进度恢复到本组三首开始前，再按照“演出失败重试次数”有界重试。失败组不计数，
  并从该组三首的第一曲重新演奏；Profile、歌曲身份、谱面、难度和流速等硬冲突仍然
  fail-closed。
- 🧭 **正确退出组曲失败页面**：组曲使用专用两阶段状态机处理“退出/继续”和确认退出页，
  严格先点第一层左侧灰色“退出”，再点第二层右侧粉色“退出”，不再复用单人模式的
  识别范围，也不会点击星石“继续”。
- 🧮 **新任务不继承旧进度**：组曲会话绑定 Maa `task_detail.task_id`。重新点击开始时，
  不再复用上一任务的暂停会话或显示旧的 `6/9` 等累计进度；旧 schema、缺失或不匹配的
  任务身份都会作废并从本次输入的第一首开始。

## 🛠️ 维护

- 📚 精简项目 Agent 指南，移除已完成修复的历史复盘、旧测试数字和重复流程，只保留
  当前长期约束、模式门禁与尚未验收范围。

## 📦 更新方式

- 🔄 已安装旧版的用户可使用软件内更新；已有便携 Python 运行库时优先下载不含运行库
  和本地谱面的更新包。
- 📥 首次安装请下载完整 Windows x64 压缩包并完整解压。
- 📢 更新后“显示公告”和更新完成弹窗均读取本包携带的这份说明。

## ✅ 验证

- 🧪 自动化：`scripts/verify.ps1` 为 `1137 passed / 6 skipped`；固定运行时检查确认
  Python 3.12、MaaFw 5.10.2、MFAAvalonia 2.12.0 与 .NET Binding 5.8.0 匹配。
- 🎮 雷电真机：自由巡演随机歌曲任务连续完成 5 组、共 15 首后由用户手动停止。
  期间两次第一曲生命归零，均正确恢复到本组开始前、退出失败演出并整组三首重开；
  两个重试组随后都保存了三张 PGGBM。15 份结果全部 stable，Native 动作全部执行并完成
  设备回读，零 underflow、零 MISS/GOOD/BAD，合计 21 GREAT，触点释放均确认成功。

## 🔒 已知限制

- ⚠️ Native 在设备短时调度异常时仍可能偶发整局失准；本版本修复的是组曲的有界恢复与
  计数，不把重试机制描述为 Native 时间轴问题已经解决。
- ⚠️ MuMu Native 仍建议关闭并使用 Legacy；组曲课题巡演和中断续跑仍需独立真机覆盖。

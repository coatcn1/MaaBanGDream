# 实时演奏 Profile v1

实时演奏对设备与游戏环境高度敏感。Profile 不是普通偏好设置，而是一次校准结果与运行环境的绑定凭据。

## 环境签名

以下字段必须全部与校准时一致：

- 分辨率；
- DPI；
- 游戏帧率；
- 演出画质；
- 音符流速。

任意字段变化都会拒绝加载 Profile，要求重新校准。首阶段仍以 `1280×720 / DPI 240 / 60 FPS / standard / 2.0` 为目标环境，但实现不把这些值当作永久常量。

## 本机数据与验收

运行生成的文件保存在 `profiles/*.json`，该路径已被 Git 忽略。程序只接受此目录内的相对 JSON 文件，防止读取任意本机路径。

新 Profile 默认应为 `accepted: false`。只有用户完成真机验收并明确确认后，后续校准流程才可以将其标记为 `true`。仓库中的 `docs/realtime-profile-v1.example.json` 仅展示格式，不能用于正式实时演奏。

## 下一步

下一里程碑是 MaaController 只观察取帧：统计最新帧延迟、实际帧率与连续丢帧，不发送触控。结果将作为 Profile 校准输入，并用于判断 MaaController 是否满足实时处理要求。

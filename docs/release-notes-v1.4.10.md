# MaaBanGDream v1.4.10

发布日期：2026-10-18

## ✨ 新功能

- 🎛️ 设置侧栏优先显示“演出设置、谱面更新”。演出设置采用单层顶部“常用 / Profile / 流速 / Native / 任务安全 / Legacy / 调试目录”七页，参数和校准记录直接展开；谱面同步、自动更新间隔与状态独立显示。
- 🎹 “演出设置 → Native”新增持久保存的“Native 协力上段首音检测（实验）”，默认关闭；普通启动即可使用界面选择。仅 Native 协力/竞演、匹配声明环境且首组为外轨普通双 FLICK 时启用，其他情况沿用原首音光门。选项在本局首次预武装时冻结，同局重建保持，下局才使用新选择；旧环境变量不覆盖界面。
- 🔋 纳入 #98 的演出前目标体力复核：常用页可设 LIVE BOOST 目标 0–3，默认 3；适用任务在选演出页按需修正，关闭弹窗后重开读回，无法确认时停止。挑战点数独立，被动一键和组曲中途续跑不离开现场修改体力。

## 🐛 修复

- 🔌 纳入 #98 的双模拟器 ADB 重连修正：空闲时实际路由变化或未知则重建主控制器与截图上下文；连接代次防止旧异步截图覆盖新连接。不改保存的设备序列号，不重启共享 ADB；任务执行中继续禁止手动重连。
- 🧹 纳入 #97 的缓存清理路径修正：部署 sidecar 的 MaaFW 调试路径与定制 MFA 白名单匹配，避免“末级布局不匹配”导致整次清理失败，保留父子目录去重。
- 💾 演出设置与谱面更新共用一个运行设置模型和保存队列。分类切换不覆盖待保存编辑；首次读取失败可重新挂载或手动刷新重试；保存耗尽后用户刷新会有限重试，成功后再读取，失败继续保留编辑。读取失败不反写默认值，已验收 Profile 修改仍需确认。
- 🛡️ Legacy 谱面辅助与主时钟保留原值；Native 开启时仅禁用对应控件，更新其他选项不强制开启旧 false 配置。

## 📦 更新方式

- 🔄 通过客户端 GitHub 更新入口安装；首次安装下载完整 Windows x64 包并完整解压。更新包不含 Python 运行库和 `resource/charts`，保留配置、Profile、日志与已有谱面；谱面从“设置 → 谱面更新”单独同步。
- 📁 更新后目录规范为 `MaaBanGDream-v1.4.10-win-x64`。请等待自动重启，勿同时开启第二个客户端；主页公告与“关于我们 → 更新日志”可查看说明。

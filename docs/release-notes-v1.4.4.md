# MaaBanGDream v1.4.4

## ✨ 新功能

- 🆕 “设置 → 性能设置 → 运行时阻止息屏”可在 MFA 运行期间保持显示器和系统唤醒。偏好会保存，关闭开关或退出程序后释放请求。
- 🖥️ 程序入口统一为 `MaaBanGDream.exe`，完整包、更新包与启动器同步使用新名称；普通用户仍可双击 `启动 MaaBanGDream.cmd`。

## 🐛 修复

- 🛠️ 修复 `ときめきエクスペリエンス！ (月島まりなver.)` 的重复曲库条目导致准备页与最终封面无法确认歌曲的问题。同名、同封面且完整谱面内容一致时自动采用最完整条目，不新增开关；`Determination Symphony` 等不同版本仍分别识别，不宽泛合并歌曲。
- 🛠️ 防息屏设置兼容旧配置，Windows 请求统一在 UI 线程申请和释放；退出程序不会清除已保存的偏好。

## 📦 更新方式

- 🔄 使用客户端 GitHub 更新，或下载完整 Windows x64 包。更新包不包含 Python 运行库和谱面库，保留个人配置、Profile、日志和调试记录；谱面仍通过“演出设置 → 谱面辅助 → 同步”维护。
- 📢 更新后安装目录自动改为 `MaaBanGDream-v1.4.4-win-x64`，客户端公告读取本次随包发布说明。

## ✅ 验证

- 🧪 自动化：`scripts/verify.ps1` 为 1260 passed / 6 skipped；定制 MFA 自动保存、GitHub 更新器、防息屏持久化及原生请求释放测试通过。完整包与更新包须通过结构、校验和、中文路径启动与目录改名检查后上线。
- 🎮 真机：月岛麻里奈版的两次单人及一次协力均通过最终封面身份门禁，第二次单人与协力完成演奏并进入结算；第一次单人后续生命归零，不计为整局演奏验收通过。

## 🔒 已知限制

- ⚠️ 电脑持续闲置的实际息屏行为仍待用户验证；新增歌曲身份规则尚未在其他任务模式增加真机覆盖，不宣称所有模式均已验收。
- ⚠️ 团队演出 Fes 不在本次版本中。PR #64 继续保留为草稿，待活动开放后完成真机测试再考虑合并。

- ⚠️ 定制 MFA 构建仍报告既有 NuGet 依赖安全告警，本次保持固定运行组合，未混入依赖升级。

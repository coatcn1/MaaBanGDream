# MaaBanGDream 公告

## 客户端更新

v1.4.6 默认开启协力成员加载页保护，可在“演出设置 → 任务安全”关闭并自动保存；Bestdori 增加默认每 24 小时的定时增量更新，可关闭或设置 1–720 小时，仅在全部实例空闲时同步。演出始终读取本地谱面。

“关于我们 → 清理缓存”会显示实际删除文件数、释放大小与未清理原因，被占用日志保留；配置、Profile 和谱面不会被清理。已有 18 首 Expert / Native 协力与一次真实空闲自动同步验证，界面已由用户查看确认。相同音符数的远端谱面修订无法从索引发现，演奏精度仍不承诺零失误。

新版本可通过客户端内的 GitHub 更新入口安装。更新期间请等待程序自动重启，不要同时打开第二个客户端。

版本改动请查看“关于我们 → 更新日志”。公告内容独立维护，内容变化时才会再次自动显示。

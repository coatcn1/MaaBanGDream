# MaaBanGDream v1.5.5

发布日期为 2026-11-24。

## 🎮 演出设置

- 🎯 「判定反馈微调」开关下可直接设定首次幅度，默认 45 ms，可调 30–45 ms。后续每次调整 30 ms。协力随机 GREAT 生效时，主动移位按键后 300 ms 内的普通键判定自动排除。
- 🎲 「协力随机 MISS」和「协力随机 GREAT」集中显示在 Native 页。随机 GREAT 仅在 Native 协力和竞演生效，优先选择曲尾安全单键，提前和延后的计划数量最多差 1。实际判定以游戏为准。
- 📸 七项实时演出任务在未选诊断选项时默认使用「按需截图＋轻量 Trace」。正常局少存，异常局保留对应阶段的排查材料。协力仍可选每局保存开场截图。

## 🐛 修复

- 🎵 准备弹窗检测要求白色实体面板，避免把相连的双 FLICK 当成「其他成员正在准备中」。移除上段首音实验及 MFA 开关，协力和竞演统一在判定线确认首音。首拍截图长时间停顿的开发保护一并合入，默认关闭。
- 🕒 协力遇到自动选歌或自动准备时，按界面倒计时开始观察最终封面。游戏提前转场时立即跟进。
- 🏆 挑战入口点击后确认选曲页出现。卡在演出选择页时重试，必要时按 ESC 回主页重新进入。
- 📊 修正 PERFECT 877 识别成 377、SLOW 67 识别成 87 的字形问题。常规演出识别到 PGGBM 后最多尝试读分 3 秒，读不出来也计入完成数并继续。
- 🛠️ MuMu Native 启动接受 0 压力上限。启动失败时，确认本轮未开放触控、启动资源已退出且仍持有本轮所有权后释放锁。

## 📦 更新方式

- 📥 Windows x64 首次使用请下载完整包并解压。已有便携 Python 的安装可用更新包，配置、Profile、日志和本地谱面会保留。
- 📢 v1.5.4 已撤下。已经安装 v1.5.4 的用户可直接更新到 v1.5.5。两种安装包均提供 SHA-256 校验文件。

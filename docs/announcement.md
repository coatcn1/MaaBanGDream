# MaaBanGDream 公告

## 客户端更新

v1.4.9 新增竞演演出普通任务，纳入最终封面启动失败处理及 Native 独立判定事件微调修正版，感谢贡献者 @suwayun1 的 PR #88、#94、#95；包含此前通过 PR #93 采纳的 PR #87 安全部分。

协力与竞演统一“跳车”选项，默认关闭。开启“生命归零后手动跳车”时停止输入并释放触点，返回桌面、切回游戏并结束任务，请按提示手动跳车；关闭时继续演奏与结算。竞演成绩数字改用实际布局坐标，避免因协力坐标偏移而读取失败。

“演出设置 → Native”的判定反馈微调与等待抖动过滤实验开关仍默认关闭、自动保存，下局生效。微调基于独立 FAST/SLOW 事件，只作用未来安全输入，保留实际执行回执等保护，不改 Profile；实际微调效果仍待专项真机验收。

此前用户竞演 9/9 完成；本版对其保存的 9 张结果图离线复放均稳定读取。该结果不代表成绩修正、手动跳车或启动失败场景已完成新实战验收。详细验证范围见“关于我们 → 更新日志”。

通过客户端 GitHub 更新入口安装时请等待自动重启，不要同时打开第二个客户端。配置、Profile、日志与谱面保留，谱面单独同步。

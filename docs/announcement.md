# MaaBanGDream 公告

## 客户端更新

v1.4.10 整理演出设置，侧栏最上方为“演出设置、谱面更新”；演出设置使用常用、Profile、流速、Native、任务安全、Legacy、调试目录七个顶部标签，取消折叠抽屉。谱面同步、自动更新与状态在独立分类中查看，两个分类共享保存队列，切换不丢待保存编辑。

“演出设置 → Native”的“Native 协力上段首音检测（实验）”默认关闭、自动保存，下局生效。仅 Native 协力/竞演、匹配环境且首组外轨普通双 FLICK 时使用，其他首组沿用原光门；普通启动即可读取界面选择，旧环境变量不覆盖设置。判定反馈微调和等待抖动过滤也继续默认关闭。

本版纳入 #98 的演出前 LIVE BOOST 目标复核和双模拟器 ADB 路由重连修正，以及 #97 的缓存清理白名单路径修正。目标体力默认 3，可在常用页调整为 0–3；零消耗测试请选择 0。保存失败后可点刷新有限重试，读取失败不会写回界面默认值。

最新 7 局 Native 竞演完整执行并释放触点，6 局成绩稳定读取、1 局不可读；同项任务已记录体力 0→3 修正及读回。七局均不符合上段首音资格，不能当作该实验的复验。当日 A to Z 协力已记录上段触发、712 PERFECT / 1 MISS 和完整释放，但缺少开头视频及双端完整覆盖；等待抖动过滤已参与实际块预测并有后续偏移使用证据；判定反馈实际采样但未达到双事件门槛，没有提交调相，不能据此宣称判定改善。

感谢 @suwayun1 在 PR #86 提供峰值、掉血兜底、弹窗填充和门控证据思路。本版采用独立受限实现，没有整包合并该 PR；掉血止损不代表整谱相位正确。详细验证与限制见“关于我们 → 更新日志”。

通过客户端 GitHub 更新入口安装时请等待自动重启，不要同时打开第二个客户端。配置、Profile、日志与谱面保留，谱面从“设置 → 谱面更新”单独同步。

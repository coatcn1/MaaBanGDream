# MaaBanGDream v1.4.12

发布日期：2026-10-23

## ✨ 新功能

- 🧾 演出设置加载和自动保存失败会写入带操作范围的日志，保留异常原因，不输出完整 Profile，便于直接定位设置问题。

## 🐛 修复

- 💾 修正 Profile 管理器在 Windows 代码页与 Python 编码不一致时的 JSON 解析失败：旧 Profile 中的中文、日文或 `☆` 等特殊字符可能使列表为空、设置显示默认值并阻止保存。本次排查确认原 Profile 和 `selection.json` 仍在，无需删除、转换或重新校准；v1.4.10、v1.4.11 的同一旧实现均受影响。
- 🔤 输入、输出和错误管道显式固定无 BOM UTF-8，并固定 Python 管道编码，不再依赖父进程控制台或继承环境。严格解码失败立即清理子进程并保留首因，避免坏流阻塞到超时；谱面同步的人类进度日志使用容错 UTF-8。
- 🛡️ 保留加载失败时禁止自动保存界面默认值的保护，不重建 Profile、`selection.json` 或用户配置；本次不新增演奏行为。

## 📦 更新方式

- 🔄 通过客户端 GitHub 更新入口安装；首次安装下载完整 Windows x64 包并完整解压。更新保留配置、Profile、`selection.json`、日志、已有谱面、运行库和体力消费保护记录；更新包不含 Python 运行库归档及 `resource/charts`，谱面从“设置 → 谱面更新”单独同步。
- 📁 更新后目录规范为 `MaaBanGDream-v1.4.12-win-x64`。等待自动重启，不要同时开启第二个客户端；本次保留既有 GitHub 历史发布。

## ✅ 验证

- 🧪 定制 MFA 完整自动保存回归通过：真实 Python 子进程覆盖父进程 CP936/UTF-8 与不同继承编码、特殊字符双向传输、错误流及坏流持续写入后的及时清理；加载失败不写默认值、保存重开与字段保留通过。
- 📂 原四份旧 Profile 完成 12 组编码加载矩阵，完整内容一致、无替换字符，双代码页下设置后端保存重开通过；实际隔离包也通过旧 Profile 加载及保存重开验证，独立审查通过。
- ✅ v1.4.12 固定 822 首曲库完整验证：2429 passed / 11 skipped；Native 自检 1932 checks，3473 文件包检查及完整包/更新包 ZIP 审计通过。
- 📦 隔离包首启、二启及真实 v1.4.11→v1.4.12 更新器升级、自动改名重启通过；原四份 Profile、选择与整个 profiles 哈希保持，2687 个谱面文件、配置标记、运行库及 ready 凭据保持。

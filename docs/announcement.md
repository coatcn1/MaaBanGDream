# MaaBanGDream v1.5.1

发布日期：2026-11-02

## ✨ 新功能

- 🎲 新增可配置的 Native 随机 GREAT，默认关闭；可调比例、难度加成与偏移幅度，计划 FAST/SLOW 均衡分配。
- 🔋 演出设置新增 LIVE BOOST 检查开关，并统一标题和说明字号；关闭检查时跳过自动补体力。
- 🧾 运行设置新增 MaaFramework 日志与调试图开关，新配置默认关闭，已有显式设置保留；修改后重启 MFA 生效。历史日志不会自动删除，任务日志和演出结果继续保留。

## 🐛 修复

- 🛠️ 随机 GREAT 与协力漏键可以同时生效，保留首音组和长条；两项在准备时冻结，修改下局生效。
- 🔋 修正火罐库存首位被裁剪及背景干扰导致自动补充跳过的问题。
- 👥 改善 LIVE BOOST 面板关闭后的入口确认，以及协力开演前成员退出后的恢复。

## 📦 更新方式

- 📥 提供 Windows x64 完整包、更新包及各自的 SHA-256 校验文件；首次使用请下载完整包并完整解压。
- 🔄 更新保留配置、Profile、日志和已有谱面。更新包不含 Python 运行库归档与本地谱面，谱面可在客户端单独同步。

## ✅ 验证

- 🧪 完整自动化验证与 Native 组合离线验证通过，具体范围以发布构建记录为准。
- 🎮 用户三局 Native 协力双开均完成：漏键计划均为 2，结算均为 2 MISS、无 GOOD/BAD，动作执行及释放完整。框架日志关闭后零增长，任务结果正常保留。

## 🔒 已知限制

- ⚠️ Native 与随机 GREAT 仍为实验功能，表现受环境影响；实际 GREAT 比例及方向不保证达到设置值。
- ⚠️ 双开漏 1 键及竞演尚未实测，不能由三局协力外推；可关闭对应开关，下局生效。

- 🎯 先在“演出设置 → 常用”开启 Native 演奏核心，再到“Native”页开启默认关闭的“判定反馈微调”；修改下局生效，关闭该选项可回退。开启后单人正式局选择方向纠偏路径；截图过慢或时钟证据失信时降级。
- 🛠️ 修复 Native 反馈异常停用后画面可能不再刷新、生命与演出结束检测持续读取旧画面的问题；停用反馈后仍继续获取新画面。
- 🎵 修正协力/竞演首拍被广域转场保护误挡的问题，保留开演前等待弹窗识别；稀疏截图下的首拍漏检仍待完善。
- 🛡️ 演奏输入、触点释放和身份门禁仍是测试重点；诊断证据用于辅助定位，不能代替实际输入和完成凭据。

# MaaBanGDream 公告

## 客户端更新

v1.4.7 Release 已撤下，当前正式下载为 v1.4.6。最终封面长标题与协力房间恢复修正版已合入 main，暂属开发候选；后续版本验证与发布完成前，请以现有正式 Release 为准。两项候选默认关闭，专项真机验收尚未完成。

v1.4.7 加速通用截图刷新、加强最终封面身份确认，并将 Native 回执与诊断写盘分离；停止时完整确认全部合法触点释放。修正新截图误标复用与单人正式模式分路，挑战生命归零后保存现场并明确失败，不自动退出或重试。

“演出设置 → Native”的掉血判定纠偏与等待抖动过滤两个实验开关均默认关闭、自动保存，修改从下一局生效。掉血窗口中三个独立连续同向 FAST/SLOW 才请求 ±2ms 调整，本局累计限 ±40ms，仅改变未来安全切片，不改 Profile。

最新同曲 Expert / Native 挑战完成 20/20、11 局 AP，合计 24 GREAT、1 MISS，输入执行、触点释放与 jlog 保存完整。本批未触发真实掉血纠偏，实际纠偏、长条暂缓、低吞吐降级及其他模式仍待专项验收，演奏精度不承诺零失误。

新版本可通过客户端内的 GitHub 更新入口安装。更新期间请等待程序自动重启，不要同时打开第二个客户端。

版本改动请查看“关于我们 → 更新日志”。公告内容独立维护，内容变化时才会再次自动显示。

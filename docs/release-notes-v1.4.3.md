# MaaBanGDream v1.4.3

## ✨ 新功能

- ♾️ 单人实时、协力、挑战、自动演出与组曲的次数上限提高到 999；填 0 表示无限演出，直到手动停止或无法安全继续的真实失败。组曲仍按完整三首循环，有限次数必须为 3 的倍数。
- 🔁 演出设置里的失败重试次数上限提高到 99，默认仍为 1。无限模式不改变重试预算和安全门禁。
- ⏩ 演出设置新增默认关闭的“不检查结果”，可跳过成绩数字检查和记录，保留安全结算推进。实时校准不适用，仍需完整成绩才能接受 Profile。

## 🐛 修复

- 🛠️ 已确认结束并安全释放触点的演出，不再因成绩识别、数字不稳定、截图、报告保存或结算恢复错误而终止后续演出；缺失成绩不会伪造。死亡、身份冲突、未完成演出及用户停止仍独立处理。
- ⚡ 组曲结算使用“最右下角安全像素 → BACK → 同一安全像素”，每步回执后立即截图检查，移除固定慢等待。
- 🏠 修复组曲快速结算后主页退出弹窗反复打开的问题：取消弹窗后被动确认主页稳定，再进入下一组。
- ♾️ 组曲跨组和失败重开改为循环，避免无限挂机累积 Python 调用栈；无限进度显示实际完成数量，不显示 0/0。

## 📦 更新方式

- 🔄 使用客户端的 GitHub 更新，或下载完整 Windows x64 包；更新包不包含 Python 运行库和谱面库，保留个人配置与 Profile。
- 📢 更新后安装目录自动改为 `MaaBanGDream-v1.4.3-win-x64`，主页展示本次公告。谱面仍通过“演出设置 → 谱面辅助 → 同步”获取。

## ✅ 验证

- 🧪 自动化：`scripts/verify.ps1` 1251 passed / 6 skipped；定制 MFA 自动保存测试通过。覆盖真实 MaaFramework 的有限次数终止/无限模式手动停止、999 次边界、99 次重试及组曲迭代循环。
- 🎮 用户已验收本轮结算容错、快速推进与主页退出弹窗恢复；新增 999 次、99 次重试和无限模式有自动化边界/停止验证，未完成对应次数的真机长时间压力测试。

## 🔒 已知限制

- ⚠️ 无限模式不会忽略真实失败或硬冲突；手动停止仍立即释放输入。它也不会修复息屏、远程连接或外设变化引起的模拟器卡顿。
- ⚠️ MuMu 继续使用 Legacy；不同演出模式的边界与随机组曲仍需分别保留真机证据。

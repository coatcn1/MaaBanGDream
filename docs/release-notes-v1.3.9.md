# MaaBanGDream v1.3.9

本次版本集中修复演出结束后的结算推进与组曲会话恢复问题。所有演出统一使用已经在协力流程验证过的安全输入节奏，不再依赖易受活动页面变化影响的可见按钮或中间页面模板。

## 🐛 修复

- 🔁 **统一结算推进**：所有演出任务在演出结束后严格循环“点击最右下角安全像素 `(1279,719)` → Android BACK → 再点击安全像素”。点击只用于加快页面动画，BACK 是唯一推进页面的输入。
- 🎼 **组曲逐页读取结果**：每次安全像素或 BACK 输入后立即检查 PGGBM，避免第一、第二首结果页在一整轮输入中被越过；一组仍要求按会话顺序原子保存三张 PGGBM。
- 🧵 **修复旧 Controller 崩溃**：每次结算输入前重新取得当前反向 Controller，避免嵌套演奏替换代理后复用旧句柄造成原生访问冲突。
- ♻️ **修复手动退出后的会话阻塞**：第三首结束后手动停止任务并自行退出结算时，下一次启动不会再报“组曲会话仍有待读取结算”。不足三张结果会封存旧会话并从新一组开始；三张均已保存时只补记完成状态。
- ⚡ **补齐一键演奏收尾**：一键实时演奏会读取 PGGBM、恢复主页后再报告完成。
- 🛟 **保留有界兜底**：结算输入耗尽后保存现场并进入 `CommonRecover`，无法恢复主页时允许重启游戏。

## 📚 文档与维护

- 📝 扩充 v1.3.8 公告，补入自上一版本以来已经合并的组曲、Special、一键演奏、发布包与更新器变更。
- ✅ 新增普通演出、协力、一键演奏和组曲结算节奏的回归测试，并覆盖手动退出后重启任务的会话恢复分支。

- 自动测试：`1110 passed, 6 skipped`。
- 运行时兼容检查：Python 3.12、MaaFw 5.10.2、MFAAvalonia 2.12.0、.NET Binding 5.8.0。
- 雷电 Native 真机完成一组自由巡演“当前曲目”：三首均为 713 PERFECT / 0 GREAT / 0 MISS，三张 PGGBM 均保存并成功返回主页。
- 随机选曲、课题巡演、多组连续和中断分支尚未分别完成真机验收；对应状态机和恢复分支已通过自动回归。

## 📦 更新方式

- 已安装 v1.3.8 的用户可使用软件内更新，优先下载不含 Python 运行库和本地谱面的更新包。
- 首次安装请下载完整 Windows x64 压缩包。
- 本地谱面继续通过“演出设置 → 谱面辅助 → 同步”单独维护。

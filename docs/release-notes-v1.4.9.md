# MaaBanGDream v1.4.9

## ✨ 新功能

- ⚔️ 竞演演出作为普通任务开放，支持活动/自由房型、满员开演、选曲、准备及竞演结算。沿用协力的 Profile、停止与错误恢复约束，无额外竞演实验开关或启动验收门槛。
- 🎹 Native 判定反馈微调改为约 5Hz 常开观测可信 FAST/SLOW，候选出现时短暂加密采样；一秒内两次独立同向事件才请求 ±15ms，未来未发布输入累计限 ±200ms。保留单槽信箱、实际执行回执、时钟、HOLD、释放及安全切片保护；实验开关仍默认关闭，不改 Profile timing offset。

## 🛠️ 修复

- 🛡️ 最终封面启动失败保留具体原因；硬身份冲突立即失败，不经过恢复或重试。其他启动失败按有限预算退出，公共 MaaFramework 回调保留布尔失败，避免异常穿透回调边界。
- 👥 协力与竞演统一“跳车”选项及“生命归零后手动跳车”提示，默认关闭。开启时停止输入并释放触点，返回桌面、切回游戏并结束任务，提示“请手动跳车”；关闭时继续演奏与结算。每次系统操作优先检查用户停止。
- 📊 竞演复用协力结算的有界推进流程，成绩数字使用竞演实际的单人布局坐标，修复已有截图因协力坐标偏移而读取失败；多人结果不作为 Profile 验收凭据。
- 🔎 包含已由 PR #93 合入的 PR #87 安全子集：亮度 V 通道、假名规范化及严格标题歧义处理。单字符补全和窄/宽框模糊覆盖未采纳。
